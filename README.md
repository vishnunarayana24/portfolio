# Portfolio Website

A modern, responsive portfolio website built with React and TypeScript.

## Features

- Responsive design
- Modern UI with smooth animations
- Project showcase section
- Contact form
- Skills and experience display

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm (v9 or higher)

### Installation

```sh
# Clone the repository
git clone https://github.com/vishnunarayana24/portfolio.git

# Navigate to the project directory
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Deployment

This project is deployed using GitHub Pages. The deployment is automated through GitHub Actions.

- The website is available at: https://vishnunarayana24.github.io/portfolio/
- Deployment is triggered automatically on pushes to the main branch
- The build process is handled by GitHub Actions
